# 1.0.4 → 1.0.5 — AG-UI 1.0 (unreleased)

## Breaking

- `ag-ui-protocol` 1.0.0 (was a 0.1.21 dev build). Consumers need `@ag-ui/client` 1.x.
- `agno` is no longer a core dependency: install `digitalkin[agno]` (agno >=3.1.1,<4) to use `digitalkin.community.agno`.
- `THINKING_*` outputs removed; reasoning travels as `REASONING_*`.
- Sources are an `ACTIVITY_SNAPSHOT` with `activityType: "sources"`, no longer `CUSTOM source_citation`. The front must render both until this version is deployed everywhere ([contract](../agui_events.md#sources)).
- The HITL runner types its input as `AgUiRunInput` (a `Protocol`: `thread_id`, `run_id`, `messages`, `tools`).
- `RUN_ERROR` for a module exception carries `message: "module execution failed"`; the detail stays in the server log.

## Added

- `RUN_STARTED.protocolVersion`.
- `AgUiStreamInput` (`digitalkin.community.agno`): AG-UI run input trigger that upgrades legacy `binary` attachments to 1.0 media parts with `metadata.fileId`.
- `SUBAGENT_FINISHED outcome: suspended` when a HITL pause interrupts open subagents.
- `RUN_ERROR code=INPUT_VALIDATION_ERROR` before `stream.error` when the run input is invalid.
- `DIGITALKIN_AGUI_*` settings (source caps, inline attachment size).

## Fixed

- Tool calls still open when a run ends are closed with `TOOL_CALL_ERROR`; after `RUN_ERROR` open items are abandoned, as the 1.0 spec requires.
- Events without an id are dropped and logged instead of carrying an empty or invented id.
- Reasoning content without a start opens its own reasoning message.

## Tooling

- `docker-compose.yml` no longer pins container names; `tests-redis` takes the first free host port in 6399–6409.
